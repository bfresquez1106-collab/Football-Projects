# Football projects

Analytics projects that each answer a football question. Practice and
exercises live in the separate `football-learning` repo; when something there
grows into a real question, it moves here.

## Projects

| Project | Question | Data |
|---|---|---|
| [nfl-model](nfl-model/) | How well can on-field data alone predict every NFL game, week by week? | nflverse play-by-play, schedules, injuries, snap counts (2021–26) |
| [broncos-seahawks-2026](broncos-seahawks-2026/) | What are Denver's chances vs Seattle in Week 6, and which levers matter most? | nflverse play-by-play 2024–26, schedules |

Give each project its own folder with a `README.md` (the question, the data,
how to run it) and a `requirements.txt`, so each one stands on its own.
