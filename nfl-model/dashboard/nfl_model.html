What moves this game

Lever and scenario values come from 2022–26 games: points scored over the model's expectation when each thing happens. They describe winning games and don't prove what causes wins, because teams that fall behind pass more and so take more sacks and turnovers.

This season's record

Each game is graded on the last prediction logged before kickoff. Brier score is the squared gap between the win probability and what happened: 0 is perfect, and 0.25 is a coin flip.

Earlier weeks, reconstructed

These games were played before predictions were being logged, so they come from the walk-forward replay: each game was predicted using only games played before its week. The data had no hindsight, but some model settings were chosen while these weeks were visible, so treat this as close to honest rather than a true live record. It's kept separate from the live record above. A tie counts as half a correct pick.
